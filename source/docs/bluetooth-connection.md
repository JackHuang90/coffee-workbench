# 网页蓝牙直连

网页可选择 Wi-Fi 或 BLE 蓝牙读取 ESP32-S3 状态。蓝牙不需要 Node、桥接程序、路由器或设备 IP，也不需要先完成 Wi-Fi 配网。Artisan 继续使用已有 Wi-Fi / Modbus TCP 连接；本次没有新增 Artisan 蓝牙。

## 使用步骤

### 通过蓝牙配置 Wi-Fi（2026-10-31 新增）

需要网页和 ESP32 都更新到本次版本。旧固件仍可读取蓝牙状态，配网区域会提示升级。

1. 打开「连接 ESP32」，选择「蓝牙直连」，点击「选择蓝牙设备」。
2. 连接后展开「Wi-Fi 设置」。2026-11-01 修正版会在此时主动发起加密配对，并保存配对关系；按系统提示完成后再点击配网授权。若 Windows 没有弹出提示，请先在系统「设置 → 蓝牙和设备 → 添加设备」中配对 `Coffee-…`，再回到网页连接。浏览器设备选择授权与系统加密配对是两件事。
3. 设备紫黄交替闪烁时，短按一下 BOOT 后松开，授权当前蓝牙连接配网 120 秒。不要长按五秒，五秒长按仍是清除网络设置。启动时一直按着 BOOT 不会确认授权。
4. 扫描并选择 2.4 GHz Wi-Fi，或手动输入隐藏 SSID，填写密码。默认 DHCP；需要固定地址时可展开填写 IP、子网掩码、网关与 DNS。允许的网站来源可以明确填写和修改。
5. 点击「测试连接」，成功获取 IP 后点击「保存并完成」。修改任何配置后必须重新测试。保存失败可重试；候选不会覆盖原来的持久配置。
6. 页面显示设备 IP，可复制到 Wi-Fi 直连或 Artisan。蓝牙状态读取仍可继续，不必加入设备热点，也不必查询热点密码。

密码仅经加密的 BLE 链路发给设备，不回显、不写网页存储。系统采用 Just Works 配对，加密用于保护传输，不提供设备身份认证；请在设备旁核对正在操作的设备并按键确认。断开蓝牙、关闭授权或 120 秒到期会撤销配网权限。配网会停止设备当前的控制会话，测试/保存不会授予温控权限。

### 读取设备状态

1. 安装含 BLE 功能的新版参考固件。旧的仅 Wi-Fi 固件不会出现在本项目蓝牙设备列表中。
2. 在支持 Web Bluetooth 的浏览器中打开工作台的 HTTPS 地址。开发电脑也可使用 `http://localhost:5173`。
3. 打开“连接 ESP32”，选择“蓝牙直连”，再点击选择设备按钮。在浏览器弹出的列表中选择自己的 `Coffee-…` 设备。
4. 收到第一份完整有效状态后才显示已连接。这里读取的温度、模式和控制归属与 Wi-Fi 使用同一套数据定义，LOCKED 的无效温度不会变为0，VIRTUAL_DEMO 仍是虚拟数据。
5. 切换连接方式、点击断开或关闭页面会清除当前遥测并断开蓝牙。切换标签保留用户已选择的蓝牙连接，也不会取消进行中的设备选择；超过三秒没有新样本立即隐藏旧读数，收到下一份有效样本后恢复。已建立会话的分片超时或丢片会丢弃该帧并重新同步，不因此主动断开配网。设备真正断线、重启或返回错误协议时仍需手动重连；关闭连接弹窗本身不会停止读取。

## 支持范围

Windows 首次加密配对与 Android/macOS 的按需配对行为不同，不能假定保护特征首次写入失败后浏览器会自动配对。固件在配网订阅时提前启动加密；网页只对明确的“连接/操作仍在进行”错误做有界重试，不重放结果不明的写入。参考 [Web Bluetooth 平台实现状态](https://github.com/whatwg/bluetooth/blob/main/implementation-status.md)。

| 使用环境                                       | 网页 BLE                                            |
| ---------------------------------------------- | --------------------------------------------------- |
| Windows / macOS 的 Chrome、Edge                | 浏览器提供 Web Bluetooth 且蓝牙可用时支持           |
| Android Chrome                                 | 浏览器提供 Web Bluetooth 且蓝牙可用时支持           |
| iPhone / iPad Safari、桌面 Safari、Firefox     | 不支持；使用原有 Wi-Fi 方式                         |
| 普通内网 HTTP，例如 `http://192.168.1.10:5173` | Wi-Fi 方式可以尝试；BLE 需要 HTTPS 或本机 localhost |
| 微信等内置浏览器                               | 不保证；用支持的完整浏览器打开                      |

浏览器可能因操作系统权限、企业策略或页面权限策略禁用蓝牙，网页会显示当前能力或连接错误。手机打开电脑的开发页时，不能用 `localhost` 代替电脑 IP；它指的是手机自己。需要蓝牙时可直接打开已发布的 HTTPS 站点。

设备选择是浏览器授权，与 Wi-Fi 的“允许的网站”列表不同。BLE 不携带 HTTP 网站来源，因此不受该列表控制；状态特征仍只提供原有遥测，另有独立的 Wi-Fi 配网特征，不公开热点或路由器密码，也没有温控命令特征。不要把设备名称或浏览器授权当作设备身份认证。

## Wi-Fi、蓝牙与 Artisan

同一台设备的 Wi-Fi 和 BLE 可以共同提供只读状态；BLE 只接受一个客户端，不能保证两个浏览器同时占用它。网页不会给 Artisan 的控制会话续期，也不会抢占其控制权。Artisan 配置仍见 [Artisan Wi-Fi 设置](../firmware/docs/artisan.md)。

两种连接在不同时间采样时，数字可能略有时间差；蓝牙不会另做温度平滑或修改单位。丢失片段、格式错误、设备重启、组帧超时或连续3秒没有完整新样本都会清空显示。Wi-Fi 配网扫描和热点流量会与 BLE 共享射频资源，实际共存表现需要板上验证。RGB 按优先级显示网络、蓝牙及控制状态，规则见[配网与灯态](../firmware/docs/provisioning.md)；灯光不证明温度有效或实际输出状态。

## 连接故障诊断

连接失败时，网页会保留浏览器标准错误和发生阶段（选择设备、建立连接、查找服务、订阅状态等），便于区分尚未连上与连上后断开。这些提示用于定位故障，不代表重复连接就能解决配对问题。

对实机观察到的 `Connection Error: Connection attempt failed.`，网页仅在建立连接阶段、同一次设备选择内等待短暂间隔并再尝试一次，用户取消后不再尝试。这个规则不会重放配网写入。配网特征发现和回复订阅也有15秒准备期限；超时会说明卡住的阶段并结束当前配网客户端，迟到的操作不能继续发送配置，遥测连接由外层继续管理。

含诊断接口的固件可通过 USB 串口发送 `BLEDIAG` 加换行，读取当前连接、订阅、加密、绑定、MTU、连接及断线计数、最近认证状态、断线原因、通知错误和固件主动关闭分类。诊断版本2还包含配网写入、入队、完整请求、响应生成和SDK接受通知的计数、最近响应码及固定拒绝阶段，便于区分请求在哪一步停止。该命令只读，不发起配对、不清除绑定、不修改网络或控制状态；输出不包含设备标识、Wi-Fi 配置或密码。计数和最近事件只保留到设备重启。错误码保留 SDK 原值，认证等待超时与固件主动断开应分别分析。

## 当前验证边界

自动化验证覆盖配网分片互通、网页生命周期、授权边界及源码构建。单台 ESP32-S3 与 Windows Chrome 的现场验证已覆盖一次设备选择后连接、BOOT 短按授权、真实 Wi-Fi 扫描/连接/保存、RESET 后自动恢复网络，以及蓝牙重新连接后的加密配网状态查询。独立 Windows BLE 接口另完成十分钟连续传输和三轮实际断线重连。

单灯在蓝牙已连接时按每三秒轮显通信状态：前两秒显示 Wi-Fi，后一秒显示蓝牙。两者在线时可见绿色与青色轮换；蓝牙传输的青色短闪也不会遮住 Wi-Fi 时段。蓝牙未连接时，Wi-Fi 在线为绿色常亮。故障、恢复、现场确认、启动及曲线/温控等业务状态按优先级覆盖轮显，详见[完整灯态规则](../firmware/docs/provisioning.md)。不同电脑与板卡的兼容性、RGB 颜色顺序、长时间高负载 Wi-Fi/BLE 共存仍需分别验收。没有新增真实传感器或执行器接线。
