# ESP32-S3 配网与网页直连

另有无需路由器的 [网页 BLE 蓝牙直连](bluetooth-connection.md)。两者共用只读状态定义；Artisan 仍通过 Wi-Fi 连接。蓝牙要求 HTTPS 或本机 localhost，不能套用下文普通内网 HTTP 的 Wi-Fi 支持范围。

HTTPS 网页、本机 HTTP 开发页和使用标准内网 IPv4 的 HTTP 网页都可以通过 Wi-Fi 读取同一局域网中的 ESP32 状态，无需额外启动 Node 桥接。本地桥接保留为兼容选项。两种方式都只读：不上传曲线、不 ARM/START/STOP，不给固件控制租约发送保活心跳。本地 PID 仿真与设备状态独立，VIRTUAL_DEMO 的温度仍是固件虚拟数据，两个固件模式都未绑定物理执行器。

## 首次使用

1. 使用本次支持配网的固件。首次启动会打开 `Coffee-Setup-…` 热点。连接设备标签上的独立密码；开发板可用 USB 串口发送一行 `SETUP` 查询热点名称、密码和配置地址。普通 `NETWORK` 查询不返回密码。完整说明见 [固件配网](../firmware/docs/provisioning.md)。
2. 手机、平板或电脑连接热点，打开系统配网弹窗；没有弹出时，在完整浏览器访问热点的网关地址，默认 `http://192.168.4.1`。该步骤无需互联网。
3. 选择或手填路由器的 **2.4 GHz Wi-Fi**，输入密码。默认 DHCP；固定 IPv4 需填写 IP、掩码、网关、DNS，避免与路由器分配地址冲突。
4. 在「允许读取状态的网站」填写网页来源。公开版本不预填私人站点来源，请填写你实际打开工作台的地址，例如 `http://localhost:5173`。以后换网站可以在配网页修改，无需为每个域名重编译。允许最多 4 个来源：HTTPS，或下文列出的本机/内网 HTTP 地址。完整链接会标准化为协议、主机和非默认端口，不保存路径。留空表示不开放跨站网页读取。
5. 点击「测试连接」，核对成功后的设备 IP 和实际网站来源，再点击「保存并完成」。测试失败或保存失败可重试，不能把测试按钮当成保存。保存成功后热点约 30 秒关闭。
6. 把手机或电脑切回同一路由器，打开已配置的网站，点击「连接 ESP32」，输入设备 IP，点击「只读连接」。如果浏览器提示访问局域网，请按需授权。网页不会自动扫描设备或自动重连。

DHCP 地址可能随路由器租约改变；可在路由器保留地址，或在配网时选固定 IP。`NETWORK` USB 查询、配网页测试结果和路由器客户端列表均可帮助确认当前 IP。热点与路由器网段重叠时，需要按配网页提示重新连接热点并访问新的网关，详见固件配网文档。

## 恢复配网与灯光

设备正常启动后先松开 **BOOT**，再按住约 5 秒，紫灯快闪后松开，清除网络和网站来源配置并回到配网；独立热点身份和密码保留。**RESET/EN 只重启并保留配置**。不要按住 BOOT 上电或同时按 RESET，那是芯片下载模式的按键操作。

提供的板卡资料对应 BOOT GPIO0、WS2812 GPIO48。蓝色慢闪表示等待配网，黄色闪烁表示连接中，绿色低亮表示已取得地址，红色间歇闪烁表示失败，紫色快闪表示松开 BOOT 确认恢复。灯光仅代表网络状态，不代表物理加热状态；实际板卡颜色、按钮接线及记忆容量仍需实测。板型与引脚依据见 [硬件资料](../firmware/docs/hardware/user-board-2026-10-29/README.md)。

## 浏览器与手机、平板

设备配网页由 ESP 本机提供，普通手机和平板浏览器可打开。**公网 HTTPS 网页读取局域网 HTTP 是另一个浏览器能力边界**：需要浏览器允许该网站访问局域网，并且托管网站策略允许该连接。建议先使用桌面 Chrome/Edge 或 Android Chrome 验证；iOS、iPadOS、内置浏览器不可保证。CORS 来源许可并不能单独解除混合内容或浏览器权限限制。

自 2026-10-30 起，`http://localhost:5173` 直接展示 Wi-Fi 连接表单，不再要求开发服务启用 HTTPS。网页和固件都允许以下来源：

| 网页来源               | 接受范围                                                   |
| ---------------------- | ---------------------------------------------------------- |
| HTTPS                  | 正常域名和规范 IPv4，沿用原来源匹配                        |
| HTTP 本机              | 精确 `localhost`，以及规范 `127.x.x.x` 回环 IPv4           |
| HTTP 局域网            | 规范 `10.x.x.x`、`172.16.x.x`～`172.31.x.x`、`192.168.x.x` |
| HTTP 公网域名或公网 IP | 拒绝                                                       |

目前不支持 IPv6 网站来源；HTTP 的 `.local`、`*.localhost` 和其他域名也不放行。端口必须准确匹配，非默认端口不能省略，例如 `http://localhost:5173` 与 `http://localhost:5174` 是不同来源。HTTP 默认80、HTTPS默认443会标准化省略。`http://127.0.0.1:端口` 保留自动选择桥接的兼容行为，也可手动切到「Wi-Fi 直连」。

**旧固件只接受 HTTPS，需先使用本次新版固件，再将实际 HTTP 网页来源添加到设备配网页、测试并保存。** 没有自动放行所有本机网站。手机访问电脑上的开发页时要使用电脑的内网 IP；手机的 `localhost` 指向手机自身。HTTP 内网页面如果没有剪贴板权限，可选中来源文本手工复制。

这些是应用允许的地址范围，不保证每种浏览器都允许实际请求。Chrome 对 `localhost` 开发有特殊处理，公网网站访问局域网则受安全上下文和权限限制，参见 [Chrome Local Network Access](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access)。不要求关闭浏览器检查或忽略证书。

如果连接失败，依次核对同一局域网、实际 IP、访客网络隔离、设备保存的网站来源和浏览器局域网权限。普通网络异常不能可靠区分 CORS、权限、CSP、设备离线等原因，页面不会伪造精确诊断。首次请求最多等 60 秒，以便处理权限提示；后续请求 4.5 秒超时。

## 连接行为

- 仅接受规范 RFC1918 数字 IPv4（10/8、172.16/12、192.168/16），端口固定 80，路径固定 `GET /api/v1/status`。不接受域名、公共 IP、URL、其他端口或重定向，不携带凭据。
- 点击连接前不请求设备、localhost 或局域网权限。前台连接按秒读取且不重叠；不存在云端设备轮询或代理。
- `null` 温度保持为空；设备身份、模式、所有者和物理锁按真实响应显示，不与本地仿真样本合并。
- 切到后台、关闭页面或点击断开会取消请求并清除状态。响应超时、格式不兼容、重启/时间倒退、设备时间连续 3 秒不更新均需手动重连。关闭连接对话框本身可保留前台读取。
- 设备 CORS 只放行已配置来源的状态 GET 和对应预检。配置写入只在设备热点接口进行；网页不能通过此只读入口改 Wi-Fi 或发控制命令。
- Artisan 仍直接访问设备 Modbus TCP 502，不经过网页，见 [Artisan 设置](../firmware/docs/artisan.md)。只读网页不会保持或接管其虚拟控制会话。

## 本地桥接兼容方式

在源码目录安装 Node 22.12+ 和依赖（`npm ci`），运行 `npm run bridge`，在同一电脑地址栏直接打开打印的 `http://127.0.0.1:8787`。不要从其他网站导航进去。该本地页自动使用桥接；托管网站选择兼容模式只显示启动说明，不会探测 localhost。

端口占用时可以先 `npm run build`，再 `node tools/local-bridge.mjs --port 8788`。桥接仅监听回环，严格校验 Host、Origin、Fetch Metadata 和每进程 CSRF；上游仍只有固定私有 IP 的状态 GET，不提供通用代理；兼容桥沿用末段 1–254 的地址限制。它不写网络凭据，也不向网页索要设备 token。

页面曲线库按网站来源隔离。旧站点、新站点和本地桥是不同来源，数据不会自动迁移；通过 `.alog` 或整库备份显式导入。首次保存新站点之前应保留原有备份。

## 验证边界

开发验证包括浏览器客户端行为、真实回环 socket、生产 C++ HTTP/CORS 处理器、配网配置/存储记录/按键状态机和固件构建。当前验证记录见 [本次交付验证](verification-provisioning.md)。没有连接实体开发板，没有烧录或擦除设备；不能据此宣称真实 Wi-Fi 配网、RGB 颜色、传感器或物理烘焙安全已验证。
