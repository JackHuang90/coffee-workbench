# Compact roasting console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ship the approved compact Chinese roasting console with trustworthy data and safe offline tracking simulation.
**Architecture:** Pure TypeScript modules own event/data and simulation semantics. Pinia coordinates the observable local session; small Vue components own chart, event editing and tracking views. IndexedDB storage remains unchanged.
**Tech Stack:** Vue 3, TypeScript, Pinia, Vite, Vitest; no additional packages.
**Spec:** `docs/console-v2-design.md`

## Global Constraints

- Visible name is 咖啡烘焙工作台; events are Chinese, internal codes only in tooltips.
- No hardware calls, backend, destructive migration or automatic confirmed events.
- Core desktop workflow fits 1440×900 and 1366×768 without page scrolling; mobile remains usable.
- Preserve all legacy data; save races and lifecycle teardown remain tested.

## Review Focus

- v1 read/save retains original raw samples and notes and does not relabel legacy events manual.
- Nulls and temporal gaps suppress derived values and tracking safely.
- Event edits cannot create contradictory phase ordering.
- Changing reference or replacing a document while simulation runs cannot leave a timer/output active.
- In-flight saves cannot mark a newer edit or document saved.
