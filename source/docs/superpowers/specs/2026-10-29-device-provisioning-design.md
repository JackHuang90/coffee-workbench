# ESP32-S3 热点配网、网络配置与恢复配网设计

日期：2026-10-29（Asia/Shanghai）。状态：按用户授权进入实现；用户追加要求同次修改网页连接，并提供开发板资料。内部参数为实现选择；不是已通过真机验证的功能。

## 用户要求与已确认硬件

- 首次启动由 ESP32 开启 Wi-Fi 热点，手机或电脑连接后进入本地配置页。
- 配置本地路由器，支持 DHCP 自动获取地址和手动固定 IPv4；确认后保存，后续上电自动连接。
- 允许访问设备的公网 HTTPS 网站来源可以修改，无需重新烧录。
- 用户确认开发板同时有 RESET、BOOT 按钮和 RGB LED。
- 用户最初提出长按 RESET 恢复配网。常见开发板 RESET 接 EN，按住时 CPU 保持复位，不能由固件检测长按。因此建议改用设备正常启动后的 BOOT 长按；RESET 保留重启功能。
- 用户提供的引脚资料标明 BOOT 为 GPIO0、RGB 为 GPIO48 的 WS2812；采用此板型配置，颜色顺序暂按 WS2812 常用 GRB，真机核对。公开版仅在 `firmware/docs/hardware/user-board-2026-10-29/README.md` 保留板型结论，原商品图已移除。图片混用 N8R2/N16R8 模组，继续保留原 N16R8 构建；其中 USB 标注不能覆盖芯片官方定义。

## 目标与本次边界

普通用户配网与修改来源不需要安装 Node、打开终端或重新编译固件。配置页全部资源由 ESP32 提供，不依赖外网字体、脚本或 CDN。

本次设计覆盖固件配网、持久化、恢复配网、状态灯，以及允许指定公网网站读取已有状态接口。按用户追加要求，同次将 Vue 页面连接改为浏览器直连，保留本地 Node 桥接作为兼容方式。源码修改、静态构建与实际公网发布分别记录，不以本地构建宣称已发布。

保留 LOCKED / VIRTUAL_DEMO 的原有物理输出禁用边界。网页跨域能力只开放只读状态，不新增网页控制、上传、心跳、Artisan 授权或远程恢复出厂接口。长按恢复配网时也撤销现有虚拟控制会话。

## 实现方式比较与建议

1. 沿用编译时填写 SSID/密码：不能满足用户提出的手机配网及无需重新烧录的要求。
2. 引入通用配网库：能较快提供门户，但需额外核验其阻塞、资源消耗、来源配置及现有控制循环适配。
3. 在现有 Arduino 固件中增加独立、有界、非阻塞的配网模块：复用 Wi-Fi / NVS 能力，配置页内嵌静态资源，保留现有控制与传输循环。建议采用此方式。

用户已明确选择热点网页配网的产品流程；第 3 项的内部实现方式及以下时间参数为本设计建议，不冒充用户已经确认的细节。

## 使用流程

### 首次配网

1. 没有有效配置时开启设备专属热点，例如 `Coffee-Setup-AB12CD`。后缀用于区分设备，不作为秘密。
2. 热点采用设备独立的 WPA2 密码。面向最终用户随设备提供 Wi-Fi 二维码/标签；开发板首次初始化可通过 USB 串口的显式本地查询取得热点凭据，用于制作标签，不打印路由器密码。热点凭据保存在独立设备身份空间，恢复网络配置时保留。
3. 手机连接后尽力触发系统配网弹窗，同时提供明确的手动入口。默认入口拟为 `http://192.168.4.1`；热点地址与路由网络冲突时采用已定义的替代私有网段，并在热点 DHCP 网关与本地查询中报告实际入口，不能强行承诺固定地址。
4. 页面支持异步扫描 2.4 GHz Wi-Fi，也支持手填隐藏 SSID；填写密码。
5. 地址方式默认 DHCP。固定 IPv4 模式填写 IP、子网掩码、网关、DNS。设备上的固定 IP 不等于路由器 DHCP 保留地址。
6. 同页提供“允许的网站”设置。仅保存标准 HTTPS origin（协议、主机、非默认端口），不保存页面路径；允许粘贴完整网站 URL 后显示规范化结果供核对。最多 4 个来源，单个最长 255 字节，无通配符、用户信息或 `null` 来源。
7. 默认网站来源由可覆盖的产品配置提供；当前仓库只有 Site 项目 ID，没有已确认的公开站点 origin，不能从项目 ID 猜地址。未设置来源时显示未绑定，用户仍可完成配网，但公网网页访问保持拒绝。
8. 点击“测试连接”后保留热点，用候选配置尝试连接路由器。获得有效地址后显示 SSID、实际 IP、网关、地址方式；用户点击“保存并完成”才提交配置。
9. 保存成功后提供设备地址和复制入口，提示手机切回路由器 Wi-Fi。给出约 30 秒倒计时后关闭热点，不将手机仍连热点误报为网站已可访问。

### 日常启动与重连

- 上电读取已保存配置，连接路由器；不要求再次确认。
- 短时断线按有上限的退避策略自动重连，不清空配置、不自动恢复任何烘焙会话。
- 普通启动持续无法连接时显示失败灯态并继续低频重试。默认不因路由器暂时关闭而自动开放配置写入口；用户可通过物理按键恢复配网。
- 候选配置测试超时（建议 30 秒）、认证失败或保存失败时保留配网页及上一份已提交配置，提示失败原因。测试失败不破坏可用配置。
- DHCP 地址发生变化时，以实时状态为准；mDNS 可作为辅助入口，但不作为唯一发现方式，也不声称公网网站可以自动扫描设备。

### BOOT 恢复配网与 RESET

- RESET/EN：普通重启，保留配置。
- BOOT：仅在固件已启动、先观察到按钮释放后才开始接受按键；消抖后持续按住 5 秒进入“待确认恢复”灯态，松开后执行一次恢复。
- 短按、中途松开、抖动均不清空配置；时间判断支持毫秒计数回绕。
- 恢复清除本应用网络设置、自定义网站来源及有关的用户配置授权；保留设备标识/热点密码和非配网业务数据。清除必须检查成功，再进入未配网状态。
- 优先原地切换到热点配网，避免按住 BOOT 时软件重启触发下载模式。如确需重启，必须在按键稳定释放后执行。
- 上电/RESET 时按住 BOOT 属于芯片下载模式机制，不能作为“长按恢复配网”的操作说明。

## RGB 指示建议

| 状态                        | 建议灯效     |
| --------------------------- | ------------ |
| 等待配网，热点已就绪        | 蓝色慢闪     |
| 正在尝试连接路由器          | 黄色闪烁     |
| 已连上路由器并取得地址      | 绿色低亮常亮 |
| 测试失败或日常连接持续失败  | 红色间歇闪烁 |
| BOOT 长按达到阈值，等待松开 | 紫色快闪     |

灯态只表示网络/配网状态，不表示传感器或执行器已经通过验证。按键确认提示优先于普通网络状态。所有灯效采用定时更新，不用 delay 阻塞循环。

板型配置描述 BOOT GPIO0/低有效、RGB WS2812/GPIO48/GRB、低亮度上限，并可覆盖或禁用。依据来自用户资料；实际电平、颜色、焊接跳线仍需真机验证。参考 SDK 载板名称不作为所有接线均一致的证明。

## 同次网页连接修改

- HTTPS 托管网页默认提供“Wi-Fi 直连”，在用户点击连接前不请求内网、localhost 或主动扫描网络；可切换本地桥接兼容模式。
- 目标限制为规范私有 IPv4、固定 HTTP 80 端口与 `/api/v1/status` 路径。不给任意 URL、重定向、令牌或命令入口。
- 页面显示当前网站来源并可复制，指导用户填入设备配网页；首次配网说明包含设备热点、DHCP/固定地址、BOOT 恢复和 RGB 灯态。
- 直连使用浏览器跨域 fetch、无凭据、禁止重定向；请求超时兼顾首次浏览器权限弹窗，拒绝后不自动重试。
- 不把浏览器笼统的网络错误假装识别成 CORS/权限拒绝/设备离线中的某一项；提供可核对的诊断步骤。HTTPS、托管 CSP、浏览器局域网权限和设备白名单都需要满足。
- 保留 v1 状态校验、空温度显示、会话变化/时间倒退/陈旧响应失联、取消竞态保护、切后台断开及手动重连。直连侧补上原来由 Node 提供的设备重启和时钟停滞检查。
- 保留现有本地曲线库，设备遥测不混入仿真曲线；只读取状态，不改变控制租约。
- 桌面 Chrome/Edge 和 Android Chrome 是首批验证目标；不声称 iOS/微信内置浏览器普遍支持公网 HTTPS 到设备 HTTP。无需用户关闭浏览器安全检查。

## 配置与来源边界

- 使用 NVS/Preferences 保存带版本及校验的有界配置记录；候选配置不提前覆盖已提交记录。提交使用可恢复的原子记录/双槽方案，断电后只能恢复完整旧配置或完整新配置。
- 持久化失败不显示保存成功、不关闭热点。用户热点凭据与网络配置分开存放，不能执行整片 NVS 擦除。
- 固定地址验证 IPv4 格式、连续子网掩码、主机地址、网关网段及明显冲突；无法仅靠表单校验保证网络中没有另一台设备占用此 IP。切回 DHCP 必须撤销之前的静态地址配置。
- 配网页写操作仅在明确的配网模式开放，并且只接受从热点接口进入的请求。AP+STA 同开时，不能让路由器侧客户端访问配网写接口。
- 配网写操作需设备生成的会话随机值，校验 Host、来源和请求长度；不提供任意反射 Origin、通用代理、跨站重置或通过公网网页添加自身到白名单的入口。
- 公网读取 `/api/v1/status` 只向已配置的精确来源返回 CORS 许可，响应声明 `Vary: Origin`；预检按固定方法/头列表处理。无 Origin 的既有本地只读客户端保持兼容。
- 跨域许可仅用于状态接口；配置页和命令接口不继承这份许可。Origin 白名单不是设备用户身份验证，未来控制功能需独立设计。
- SSID 等来自无线环境的文本必须转义显示，路由器密码不回显、不放 URL、不写日志、不在状态接口返回。不承诺普通 NVS 自带静态加密。
- 新配网构建不在恢复后重新导入旧编译凭据。旧发布物保持原样；开发用本地凭据配置仅可通过明确的旧构建选项保留，不作为正常产品流程。

## 模块与实时性

- 可原生测试的配置校验、配网状态机、按键与灯态决策核心。
- ESP 专属 Wi-Fi/NVS/GPIO 适配器，以及独立的配网页请求处理器。
- 配网页静态文件嵌入程序 Flash，避免为初版增加文件系统分区和额外烧录步骤；新增页面传输不可复用现有仅约一个状态包大小的发送缓冲。
- Wi-Fi 事件通过有界队列交给主循环处理，不在事件线程直接修改控制器或调用非线程安全逻辑。
- 扫描、等待连接、DNS 门户处理、页面传输和 LED 动画都必须有预算/超时；不得在控制 tick 路径增加长时间等待。NVS 写入只在明确配置流程执行，写入失败反馈到页面。
- 原有控制器、USB、Modbus 及 watchdog 回归；网络配置切换和恢复先撤销虚拟控制会话、关闭旧客户端，不自动重新授予控制权。

## 验证与交付要求

- 原生测试：无配置/坏记录/断电提交恢复；DHCP 与固定地址往返切换；非法网关/掩码/来源；候选失败回滚；保存失败；重连退避；按键抖动/5 秒阈值/松开确认/启动时按下/计时回绕；灯态优先级。
- HTTP 测试：仅热点接口可配置；AP+STA 隔离；请求防伪；来源精确匹配；允许/拒绝来源与 OPTIONS；路由器密码不泄漏；原只读与虚拟命令契约不回退。
- 固件构建：锁定与虚拟两种配网构建均使用固定 SDK 依赖；明确未知板型、禁用 LED 的构建状态，不能写成实际板卡通过验证。
- 真机验收：手机/电脑连接热点，DHCP/静态地址配网，错误密码重试，保存后断电重连，路由器掉线恢复，RESET 保留配置，BOOT 长按清除配置，灯色/亮度与网页结果一致。
- 浏览器验收：Android Chrome 与桌面浏览器验证配网页；公网 HTTPS 读取需实际允许来源、部署策略和浏览器授权共同通过；iPhone/iPad 的公网直连另列实测结果。
- 未取得真实硬件前可以完成软件与参考构建，但不得自动烧录、擦除设备或宣称真机通过。
