# 网页蓝牙配网与 RGB 整合验证记录

日期：2026-10-31。已实现新版网页蓝牙配网及 ESP32-S3 RGB 工作状态，不执行设备刷机或网站发布。

## 功能

网页与设备共用一条 GATT 会话。用户选择蓝牙设备后打开 Wi-Fi 设置，现场短按 BOOT 确认，再扫描或手填网络、测试和保存；支持 DHCP、固定 IPv4、明确的网站来源及设备 IP 复制。旧固件仍可读取遥测，配网入口提示升级。密码发送后清空，不在网页保存或日志回显。

设备使用独立加密配网特征，实体按键授权有效 120 秒，并绑定当前连接。五秒 BOOT 长按恢复保留。网络校验、测试代数和双槽存储与热点流程共用。所有 Wi-Fi、NVS 与控制器操作仍由主循环执行。

灯态覆盖启动、未配网、蓝牙连接与订阅、配网授权、Wi-Fi 尝试连接/离线/在线、曲线接收/装载、数据传输和虚拟温控，按明确优先级显示。RGB 使用单一异步驱动，无延时等待，默认 GPIO48、GRB、低亮度。完整规则见[配网与灯态](../firmware/docs/provisioning.md)。

## 测试与审查

先编写失败测试，再实现和修复。整合测试启用本机 C++ 编译器，包含浏览器与生产固件分片编解码的双向互通，覆盖中文名称、最小与较大载荷、序号回绕及缺失片段。

独立审查发现并修复了三个问题：配网响应阻塞遥测、保存中仍能编辑表单、断线后迟到的保存成功提示。对应回归测试先复现失败，再确认通过。最小 MTU 和配网拥塞下，两条通知通道交替发送，完整遥测仍能持续组装。

最终网页格式检查、静态检查、类型检查、生产构建均通过，**36 个测试文件、549 项测试全部通过，无跳过**。固件两种模式的 15 组原生 C++ 套件、门户脚本及 22 项 Python 测试全部通过；SDK 的 LOCKED、VIRTUAL_DEMO 和关闭 RGB 三个环境全部构建成功。两个发布镜像的应用单函数最大栈帧为 1632 字节，小于 2048 字节检查上限；发布收集通过源码一致性核验、离线镜像检查和合并。

实际浏览器已检查连接入口和中文灯态说明；界面截图保存在 `docs/evidence/ble-setup-rgb-2026-10-31.png`。浏览器未连接实体蓝牙设备，截图不作为真机配网成功的证据。

## 尚需真机验收

未连接或刷写实体设备。需要在实际板上确认系统蓝牙配对、BOOT 授权、Wi-Fi 扫描/密码错误/保存后重启、Wi-Fi 与 BLE 共存，以及 RGB 实际颜色、时序和亮度。Just Works 加密不提供设备身份认证，需在设备旁确认。

LOCKED 与 VIRTUAL_DEMO 均未绑定真实执行器；灯态仅反映设备实际的软件状态。网页本地仿真不会触发设备模拟温控灯态。
