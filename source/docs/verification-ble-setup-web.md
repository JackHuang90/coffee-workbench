# 网页蓝牙配网验证记录 — 2026-10-31

已在现有 `BleDeviceClient` 的 GATT 服务中加入可选的 Wi-Fi 配网功能。不会打开第二个设备选择器、建立第二条连接或重复查询遥测特征。只有用户点击配网操作后，才查找配网特征并订阅响应。旧固件缺少配网特征时显示升级提示，遥测继续工作。

## 公开接口

- `DeviceClient.provisioning?: BleProvisioningClient`：只在已订阅的蓝牙会话提供此可选能力。断线、取消或遥测失效时，由蓝牙客户端释放。
- `BleProvisioningClient.request(op, body = ""): Promise<SetupState>` 和 `dispose()`。操作为 `state`、`unlock`、`scan`、`test`、`save`、`close`。初始化及逐片确认写入通过同一队列串行执行。写入加密特征时，系统可能显示配对提示。浏览器写入超时后，若底层操作仍未完成，将拒绝新写入并提示重连，防止操作重叠。
- `encodeSetupFrames(bytes, sequence)` 和 `SetupFrameAssembler`：采用 0x52/1 头、小端序 sequence/total/offset，默认每片 20 字节，消息最多 4095 字节；接收组装使用固定十秒期限。
- 配网写入 UUID：`BLE_SETUP_WRITE_UUID` = b4e7a003-9d56-4f1b-a6e0-7d31c2f84590；响应通知 UUID：`BLE_SETUP_NOTIFY_UUID` = b4e7a004-9d56-4f1b-a6e0-7d31c2f84590。
- 请求为 UTF-8 `id\nop\nbody`；使用 URLSearchParams 编码现有门户字段 `ssid,password,mode,ip,mask,gateway,dns,origins`。保存请求正文严格为 `revision=N`。响应通过 `{id,code,data}` 中的 id 关联请求；code >= 400 时返回错误，持久化失败后仍可重试保存。

## 界面行为

面板支持短按 BOOT 授权、扫描或手填隐藏网络名称、密码输入、DHCP 或固定 IPv4、明确可编辑的网站来源、连接测试轮询、绑定候选版本的保存及实际 IP 复制；剪贴板不可用时提示手工复制。测试操作返回的候选版本必须与后续 Ready 状态一致，避免其他入口修改候选配置后误获保存资格。测试期间编辑表单会使迟到的成功结果失效。保存成功后会再次读取状态，因为固件的保存确认本身不含 IP。持久化失败时可以用相同测试版本重试。

密码在提交测试时立即清空，并在授权过期或撤销、断线及组件卸载时清理。不写入浏览器存储或日志，也不回显。面板卸载会停止界面轮询并清空本地状态，不释放共用的遥测会话。RGB 说明遵循固件优先级，其中已授权紫色单闪位于最近传输之后、蓝牙连接指示之前；没有新增物理控制功能。
